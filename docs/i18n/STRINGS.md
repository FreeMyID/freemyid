# User-facing string inventory (partial)

This is a text-only inventory of fixed English copy located in the wizard and dashboard rendering modules. It records visible wording, source lines, context, and interpolation/plural notes. It does not document implementation, comments, validation rules, or dynamic data values. String locations can change; recheck citations when the source is edited.

**Scope limit:** Morgan's CLAUDE-024 authorization permits text-only reading of consent, practice-mode, and sending/outbox copy for this inventory; no source files were changed. This remains partial because mail-security and credential guidance and data-sourced checklist copy are excluded. Fixed validation templates are included with placeholders; actual user-entered or stored values are not. The in-house team should own the protected categories or amend the acceptance scope. No Spanish UI is shipped by this document.

## Fixed messages with dynamic values

For the messages above, braces denote values inserted at runtime. They are template placeholders only; no saved or user-entered values are reproduced. Counts may need language-specific plural handling rather than literal suffix substitution. Messages from mailbox validation are excluded because they contain security and credential guidance.

## Deliberate exclusions

- Mailbox setup, account credentials, security warnings, and related copy are excluded as mail-security material.
- Checklist wording and site-specific instructions supplied by data files are excluded; this inventory does not reproduce private data-source text.
- User-entered values, outgoing email bodies/subjects/addresses, and generated listing details are not enumerated as fixed UI copy. Fixed validation templates are included with placeholders where applicable.
- This is not a claim that Spanish UI exists or that the catalog or feature set is complete. Confirm scope with the owner before treating this partial inventory as meeting the “every string” acceptance criterion.
