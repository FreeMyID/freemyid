## Scope notes

- This inventory covers the selected exposure, search-engine, and monthly-summary messages. It is not a complete inventory of all CLI commands.
- JSON schema names, field keys, status enums, CLI command names, and IDs are interface data, not user-facing prose to translate. Human-readable `status_text` and other string values remain visible wording.
- Checklist titles, instructions, tips, and URLs are sourced from checklist data. They are not reproduced here; any future translation of that data needs a separate source inventory and review.
- This document is a translation aid only. No translated CLI is shipped.
