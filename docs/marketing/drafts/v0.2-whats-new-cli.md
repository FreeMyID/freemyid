## Post (forum, Mastodon thread, Discord; edit to fit)

Free My ID 0.2.0 is out. It is a local-first, AGPL tool that asks people-search and data-broker sites to remove your listings, then keeps checking. No account. Your details are stored on your own machine.

0.2 is the "every platform" release. On Linux and macOS it is command line only: there is no desktop app for those systems yet.

- Install: `pipx install freemyid` (the package carries the small sample broker list, not the full one).
- `freemyid doctor` says what is ready on this machine and how to fix what is not (`--json`, `--offline`).
- `freemyid exposure` looks you up on the sites that allow a plain visit and gives a 0-100 score with its coverage (how many sites were checked). `--offline` fetches nothing; results from the last 24 hours are reused. It does not get past bot protection, and a low score only speaks for the sites checked.
- `freemyid checklist list|show|done|undo`: the identity-safety checklists.
- `freemyid run --dry-run` searches and reports, and sends nothing. `freemyid run --headless` is for cron or systemd and fails closed (stops and says why).
- `freemyid setup --from setup.yaml`: set up without the wizard.
- Secrets without a desktop keyring: OS keyring, passphrase file or systemd-creds (`freemyid secrets status|migrate`).
- Schedulers: a systemd user timer on Linux and a launchd agent on macOS (install, remove, status).
- `--json` on the read commands, with versioned documents and documented exit codes (docs/CLI.md).

Limits, plainly:
- The macOS scheduler is tested on CI, not yet on real Mac hardware.
- The Docker image is not public yet. Do not rely on it.
- With no keyring and no passphrase file or systemd-creds, `doctor` reports the secrets check as failed (exit 1) until you provide one.
- It works on people-search and data-broker sites only. It does not stop hacking or change what any platform does with your account.
- The first run uses the sample broker list; the full list is a later step.

Code: AGPL. The public sample broker data is CC BY-NC. Repo and docs: freemyid.org/developers/.
