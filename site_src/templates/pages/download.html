Windows may show a blue warning. Here's why, and what to do

{# source: installer is not code-signed (.github/workflows/build.yml release notes "not code-signed yet"); SmartScreen wording = Windows dialog text #}

Windows shows "Windows protected your PC" for new programs that haven't paid for a publisher certificate yet. Free My ID is free and hasn't bought one yet. The warning doesn't mean anything is wrong.

{# WR-10; families page = /families/ #}

Not sure about this step? Ask a family member to sit with you. Here's a one-page guide for them.

    {# source: file name from .github/workflows/build.yml (cp to FreeMyIDSetup.exe); Downloads folder = browser default #}
  1. 1

    Open the file you downloaded

    It's called FreeMyIDSetup.exe. You'll usually find it in your Downloads folder, or at the bottom or top-right of your web browser.

  2. 2

    Click the small words "More info"

    If a blue box says "Windows protected your PC", don't click "Don't run". Click More info instead.

    {% set ss_step = 1 %}{% include "partials/smartscreen.html" %}
  3. 3

    Check the name, then click "Run anyway"

    Make sure it says the app is FreeMyIDSetup.exe. It will say "Unknown publisher"; that's expected. Then click Run anyway.

    {# WR-19: safety line before Run anyway. "Unknown publisher": unsigned installer (build.yml release notes) #}

    Only do this if you downloaded the file from this page or from our GitHub releases page. If it came from anywhere else, delete it.
